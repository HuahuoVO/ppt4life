# ppt4life · 多场景 PPT 制作技能

> “PPT for life” —— 给每一位要靠汇报讨生活的人。先把场景选对，再把内容做对。

## 概述

PPT 没有万能模板：**给评审专家看的和给公司领导看的，是两套完全不同的逻辑**。
本技能启动后**先让使用者选择汇报对象**，再加载该人群专属的「内容逻辑 + 版式布局 + 配色 + 话术」，最后统一产出 16:9 可编辑演示文稿。

---

## 第 0 步：选择汇报对象（必须先问，禁止擅自假设）

**收到制作请求后，第一步就是让使用者选场景。** 用下面二选一（或多选）呈现，等其确认后再继续：

| 选项 | 面向谁 | 典型场景 | 加载 |
|---|---|---|---|
| **A. 科研 / 技术人群** | 评审专家、基金委、学术委员会、答辩评委 | 杰青·优青·青年基金 A/B 类、国自然、科技奖励报奖、论文/学位答辩、教学比赛课件 | `profiles/science-research.md` |
| **B. 公司领导 / 高管** | 老板、管理层、决策层 | 年终总结、工作汇报、项目汇报、方案提案、述职、争取资源/预算 | `profiles/corporate-leader.md` |

若用户一次要“两份（既有科研又有领导）”，分别按各 profile 各做一套，不要混用。

**选完后**：加载对应 profile，按其中的内容逻辑、结构、版式与配色执行；通用排版与生产规范从 `references/` 取。

## 工作流（选定场景后按此推进）

```
0 选择汇报对象（科研技术 / 公司领导）
   ↓
1 需求澄清（场景细分 / 时长与页数 / 素材 / 是否有公司VI或单位LOGO）
   ↓
2 定核心主张（按该人群逻辑：科研=三个为什么；领导=结论先行/金字塔）
   ↓
3 分场景结构（套该人群的页面骨架，产出逐页脚本）
   ↓
4 版式与视觉（通用版式法 + 该人群专属配色与图文规范）
   ↓
5 生成演示文稿（优先 PPTX，其次 16:9 高保真 HTML）
   ↓
6 自检（通用清单 + 该人群专属清单）
```

### 第 1 步：需求澄清
至少确认：**场景细分**（见 profile）、**汇报时长/页数**（未给则按约 1 分钟/页倒推并标注）、**素材是否提供**、**16:9**（默认）、**是否提供单位/公司 LOGO 或 VI 主色**。信息缺失一次性列出请用户补齐或授权假设。

### 第 2～3 步：内容逻辑与结构
- **科研技术** → 三个为什么（为什么选你/为什么做这方向/为什么能做成），页面骨架见 `science-research.md`。
- **公司领导** → 结论先行 + 金字塔原理（SCQA），**行动标题**（标题即结论句），页面骨架见 `corporate-leader.md`。
通用要求：一页一核心，文字关键词化，产出“逐页脚本文档”（页标题 + 要点 + 需配图表 + 本页唯一结论）。

### 第 4 步：版式与视觉
- **通用版式法**：加载 `references/layout-guide.md`（五大版式 + CRAP 四原则 + 三三原则 + 栅格分区 + 蒙版）。
- **人群配色与图文**：按所选 profile 中的配色与视觉规范执行；色板取 `assets/palettes/palettes.md`。
- 禁止随手摆放与花哨装饰；所有视觉决策服务于“让对方 3 秒抓住结论”。

### 第 5 步：生成
加载 `references/production.md`：优先可编辑 **PPTX**（真文字、用母版固化），否则产出 **16:9 高保真 HTML**；图片缺高清原图时用矢量/示意代替，不用模糊截图；文件保存后提示用户可下载。

### 第 6 步：自检
先过通用清单（`references/production.md` 末尾），再过该 profile 的专属清单。

## 资源

### profiles/（按选择加载其一，决定内容逻辑与配色）
- `science-research.md` —— 科研技术人群：三个为什么、评审导向、分场景页面骨架（优青/杰青·青年基金、国自然、报奖、论文学位答辩）、学术配色、答辩问答与常见坑。
- `corporate-leader.md` —— 公司领导人群：结论先行/金字塔原理/SCQA、行动标题、Executive Summary 横幅、RAG 状态、三板斧版式、商务配色、汇报话术与结尾升华。

### references/（通用，任何场景都适用）
- `layout-guide.md` —— 通用排版布局：五大万能版式、CRAP 四原则、三三原则、栅格分区与多页型、蒙版技巧、排版自查。
- `production.md` —— 生产规范：PPTX/HTML 产出标准、母版与字体嵌入、16:9 与工程限制、通用自检清单。

### assets/
- `palettes/palettes.md` —— 科研向（学术蓝）与领导向（商务蓝/高级灰/暖棕 + RAG 状态色）配色板，直接取用 HEX。

> 扩展：后续新增人群（如面向学生授课、面向客户销售）时，只需在 `profiles/` 增加对应 profile 并在第 0 步选项中登记。
