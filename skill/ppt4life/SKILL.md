# ppt4life · 多场景 · 图文并茂 PPT 制作技能

> “PPT for life” —— 给每一位要靠汇报讨生活的人。先把场景选对，再把内容做对，还要**图文并茂**。

## 概述

PPT 没有万能模板：**给评审专家看的和给公司领导看的，是两套完全不同的逻辑**。
本技能启动后**先让使用者选两件事**——① 汇报对象 ② 图文配比，再加载对应的「内容逻辑 + 版式布局 + 配色 + 配图策略 + 话术」，最后产出 16:9 可编辑、**图文并茂**的演示文稿。

**两条硬规则**：
1. 先选场景，禁止擅自假设。
2. **图文并茂**：任何一页都不允许是纯文字段落墙，每页至少配 图 / 表 / 逻辑图示 / 图标 之一。

---

## 第 0 步：先问两个选择（必须，禁止擅自假设）

### 选择一：汇报对象（单选）

| 选项 | 面向谁 | 典型场景 | 加载 |
|---|---|---|---|
| **A. 科研 / 技术人群** | 评审专家、基金委、学术委员会、答辩评委 | 杰青·优青·青年基金 A/B 类、国自然、科技奖励报奖、论文/学位答辩、教学比赛课件 | `profiles/science-research.md` |
| **B. 公司领导 / 高管** | 老板、管理层、决策层 | 年终总结、工作汇报、项目汇报、方案提案、述职、争取资源/预算 | `profiles/corporate-leader.md` |

### 选择二：图文配比（单选，默认推荐“均衡”）

| 选项 | 含义 | 适用 |
|---|---|---|
| **图多** | 视觉主导，文字只做关键词标注 | 品牌/方案展示、产品发布、年度亮点、对外宣讲 |
| **均衡（推荐）** | 图文并茂，图与文各司其职 | 绝大多数汇报/答辩 |
| **字多** | 信息密集，但**仍禁止纯文字墙**，用表格/逻辑图化解 | 数据分析、技术方案细节、制度流程 |

> 若用户一次要“多份（如既有科研又有领导）”，分别按各 profile 各做一套，不要混用。

**选完后**：加载对应 profile 决定内容逻辑与配色；再从 `references/` 取通用排版、配图与生产规范。

## 工作流（完成两选择后按此推进）

```
0 选择：① 汇报对象  ② 图文配比
   ↓
1 需求澄清（场景细分 / 时长与页数 / 素材 / 公司VI或单位LOGO）
   ↓
2 定核心主张（科研=三个为什么；领导=结论先行/金字塔）
   ↓
3 分场景结构（套页面骨架 → 逐页脚本，每页标注“需配什么图”）
   ↓
4 配图与素材（自绘图表 / 浏览器搜索下载 / AI 生图；落地到 assets/img）
   ↓
5 版式与视觉（通用版式法 + 人群配色 + 图片排版）
   ↓
6 生成演示文稿（优先 PPTX，其次 16:9 高保真 HTML）
   ↓
7 自检（通用清单 + 人群专属清单 + 配图清单）
```

### 第 1 步：需求澄清
至少确认：**场景细分**（见 profile）、**汇报时长/页数**（未给则按约 1 分钟/页倒推并标注）、**素材是否提供**、**16:9**（默认）、**是否有公司 VI / 单位 LOGO**。信息缺失一次性列出请用户补齐或授权假设。

### 第 2～3 步：内容逻辑与结构
- **科研技术** → 三个为什么（为什么选你/为什么做这方向/为什么能做成），页面骨架见 `science-research.md`。
- **公司领导** → 结论先行 + 金字塔原理（SCQA），**行动标题**（标题即结论句），页面骨架见 `corporate-leader.md`。
- 产出“逐页脚本文档”：页标题 + 要点 + **本页需配的图/表**（关键！）+ 本页唯一结论。一页一核心，文字关键词化。

### 第 4 步：配图与素材（图文并茂的关键）
加载 `references/visuals.md`，按“真实、合规、清晰”优先选择来源：
1. **用户提供素材**（实拍/产品图/LOGO）——最优先。
2. **浏览器搜索下载真实素材**——用 `bsk` 驱动真实浏览器搜索并下载，手册见 `references/browser-images.md`（免版权图库优先）。
3. **AI 生图**——缺现成素材的概念/背景/插画，用 `ImageGen` 工具生成（ToolSearch 发现 → DeferExecuteTool 调用）。
4. **矢量自绘**——数据图/流程图/逻辑图/矩阵，**优先自绘**（最严谨、可编辑）。
- 落地规范：统一存 `assets/img/`、宽 ≥1920px、比例不变形、风格统一、来源合规；全图压字加 30%–50% 蒙版。
- 若 `bsk`/`ImageGen` 不可用，**不要卡住**，回退到矢量自绘并说明。

### 第 5 步：版式与视觉
- **通用版式法**：加载 `references/layout-guide.md`（五大版式 + CRAP + 三三原则 + 栅格分区 + 蒙版）。
- **人群配色**：按所选 profile 执行；色板取 `assets/palettes/palettes.md`。
- 图文配比落地：图多→大图/全图/拼版；均衡→左文右图、上结论下图表；字多→表格化 + 逻辑图 + 关键句加粗。

### 第 6 步：生成
加载 `references/production.md`：优先可编辑 **PPTX**（真文字、母版固化），否则 **16:9 高保真 HTML**；图片用本地 `assets/img/` 的真实文件嵌入，**不用模糊截图占位**；保存后提示用户可下载。

### 第 7 步：自检
先过通用清单（`production.md` 末尾）→ 配图清单（`visuals.md` 末尾）→ 该 profile 专属清单。

## 资源

### profiles/（按选择加载其一，决定内容逻辑与配色）
- `science-research.md` —— 科研技术人群：三个为什么、评审导向、分场景页面骨架（优青/杰青·青年基金、国自然、报奖、论文学位答辩）、学术配色、答辩问答与常见坑。
- `corporate-leader.md` —— 公司领导人群：结论先行/金字塔原理/SCQA、行动标题、Executive Summary、RAG 状态、三板斧版式、商务配色、汇报话术与结尾升华。

### references/（通用，任何场景都适用）
- `layout-guide.md` —— 通用排版布局：五大万能版式、CRAP 四原则、三三原则、栅格分区与多页型、蒙版技巧、排版自查。
- `visuals.md` —— 配图策略：图多/均衡/字多、图文并茂铁律、配图来源优先级、AI 生图（ImageGen）、图片落地规范与配图自查。
- `browser-images.md` —— 用真实浏览器搜索并下载配图（BrowserSkill / `bsk` CLI 集成手册）：会话生命周期、观察-操作循环、图库/搜索引擎取图流程、合规与回退。
- `production.md` —— 生产规范：PPTX/HTML 产出标准、母版与字体嵌入、16:9 与工程限制、通用自检清单。

### assets/
- `palettes/palettes.md` —— 科研向（学术蓝）与领导向（商务蓝/高级灰/暖棕 + RAG 状态色）配色板，直接取用 HEX。

### scripts/
- `fetch-images.py` —— 一键用 BrowserSkill(bsk) 搜索并下载配图：起会话→搜图→抽链→下载到 `assets/img`→停会话，并写 `_sources.json` / `_sources.md`；`--fit 16:9 --max-width 1920` 可**居中裁剪+等比限宽**，`--style card` 可**统一圆角+描边观感**（均需 Pillow）；`--cite` 可额外生成一页 16:9 的 `图片来源.pptx`。用法见 `references/browser-images.md` 第 3.5 节。

> 扩展：新增人群（如面向学生授课、面向客户销售）时，只需在 `profiles/` 增加对应 profile 并在第 0 步选项中登记。
