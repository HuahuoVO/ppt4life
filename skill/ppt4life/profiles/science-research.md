# 面向科研 / 技术人群 · 答辩汇报 PPT 规范（Profile A）

> 适用：杰青·优青（2025 起青年科学基金 A/B 类）、国家自然科学基金、人才与科技奖励（报奖）、论文/学位答辩、教学比赛与课件汇报。
> 核心认知：**评审看的是“贡献与创新”，不是炫技**。一切围绕“讲得清、记得住、信得过”。

## 1. 内容逻辑：评审导向的“三个为什么”

每一页都应服务于主线，用三问自检：
1. **为什么选你？** → 学术定位、学术标签、代表成果（质量 > 数量）、学术影响力。
2. **为什么做这个方向？** → 领域痛点、科学问题重要性与原创性、研究空白。
3. **为什么能做成？** → 方案可行性、技术路线、前期基础/预实验、团队与平台支撑。

**叙述原则**：
- 先讲“问题/贡献”，再讲“做了什么/发了什么”（评委先要知道你在解决什么）。
- 成果凝练为 **2–3 个核心创新点**，每个 ≤3 个小点，按“背景意义 → 成果特色 → 应用与评价”展开；**绝不罗列论文清单**。
- 讲“人话”：评委不全是小同行，避免术语堆砌。
- 一页一核心（每页主文字 ≤3 行）。

## 2. 分场景页面骨架

### A. 优青/杰青/青年基金 A·B 类（8–15 分钟，约 25–35 页）
```
01 封面（项目名/姓名/单位/LOGO/日期/基金类别）
02 目录/汇报框架（进度导航）
03–04 个人简介与学术标签（1 句话定位 + 关键节点图示）
05–07 研究背景与科学问题（领域痛点→现有局限→核心科学问题 1–2 个）
08–11 研究内容与创新点（分模块 + 技术路线图 + 原创性对比）
12–13 研究方案与可行性（预实验/前期基础 + 可行性分析）
14–15 研究计划与预期成果（分年度甘特图 + 成果指标）
16 团队与平台支撑（量化到数字）
17 总结/致谢
```
评审关注：教育经历、主要学术成绩（占比最高）、原创性、发展潜力、单位支持。

### B. 国家自然科学基金（面上/重点等，8–10 分钟，约 15–20 页）
立项依据与科学问题 → 研究内容与目标（1–2 核心问题拆 3–4 子内容）→ 研究方案与技术路线（流程图）→ **创新性单独 1 页**（具体表述，如“首次将 XX 应用于 XX”）→ 研究基础与可行性（预实验/平台）→ 年度计划与预期成果（甘特图）→ 经费预算 → 致谢。

### C. 科技奖励 / 报奖答辩（5–10 分钟）
项目简介(一句话价值) → 立项背景与总体思路 → **主要创新点 2–4 个**（技术+数据+应用证明，对比突出原创）→ 应用推广与效益（量化）→ 第三方评价/查新/获奖 → 与国内外同类指标对比表 → 总结与展望 → 致谢。

### D. 论文 / 学位答辩（10–15 分钟，约 15–25 页）
封面（题目与论文一致）→ 目录 → 研究背景与意义 → 文献综述（**评述指出空白**，非罗列）→ 研究问题与目标 → 思路方法/技术路线（流程图）→ **结果与分析（占比最大）**：每图配一句“看出什么→证明什么”，敢展示关键数据（含阴性结果体现严谨）→ 讨论 → 结论与展望（与开篇呼应 + 不足）→ 致谢。

## 3. 视觉规范

### 3.1 配色
- 全篇**主色 + 1–2 辅助色，≤3 色**；首选 **学术蓝 + 灰白 + 少量强调橙/红**。
- 深字浅底、高对比；强调色只用于关键数据、核心科学问题、创新点关键词。
- 色板见 `assets/palettes/palettes.md`（学术蓝 / 深海军蓝 / 灰度专业）。

### 3.2 字体与图文
- 无衬线字体（微软雅黑/思源黑体/Arial），全篇 **≤2 种**；**拒绝过细字体**（投影易糊）。
- 字号：标题 ≥24pt（章节大标题 36–44pt），正文 18–24pt，重点 ≥24pt。
- **图 > 表 > 字**：技术路线用流程图、对比用图表、数据用高质量数据图；**每个图只让评委看一个结论**（关键数字放大/变色/加圈），别丢整张大表。
- 留白充足、严格对齐；每行 ≤20–25 字。

### 3.3 版式
加载 `references/layout-guide.md`：按内容逻辑选版式（拦腰/环绕/分割/卡片/全图），套栅格与“标题区/图文区/结论区”分区，按 CRAP 四原则排布，遵循三三原则。

### 3.4 动画与工程规范
- 动画克制稳重（淡入/推进），用于引导视线与替代激光笔提示；无花哨跳转与音效。
- 16:9；文件 ≤200M；嵌入媒体用通用格式；图片用高清原图，不清晰则重绘。

### 3.5 配图（科研向，图文并茂）
- 科研场景默认**“均衡”**；纯数据/公式页可偏**“字多”**但必须用表格/逻辑图化解，禁止纯文字墙。
- 科研优先**矢量自绘**：技术路线图、机理示意图、数据图（最严谨、可编辑、无版权风险）。
- 需要实景/实验装置/样品照片时，优先用**自有实验图**；缺图时用真实浏览器搜索（`references/browser-images.md`）或 AI 生图（`ImageGen`）做**示意/概念图**，并注明“示意图”。
- **绝不用 AI 图伪造数据、实验结果或图表**；示意图与真实数据图要区分清楚。

## 4. 答辩问答与常见坑

**高频问题应对**（详见下表思路）：
| 类型 | 应对思路 |
|---|---|
| 创新性“跟别人有什么不同” | 用“背景意义→成果特色→应用评价”讲原创，配对比图，不罗列论文 |
| 可行性“凭什么能做成” | 亮预实验/前期数据 + 方法与平台支撑（量化） |
| 科学问题“值不值得做” | 用文献/数据说明痛点与空白，突出科学价值 |
| 技术细节 | 简明给主线，细节放附录/口头补充 |
| 局限与不足 | 诚实陈述 + 明确未来计划（体现批判性思维） |

**必须规避的坑**：罗列论文清单；术语堆砌；每页塞满文字；无重心面面俱到；关键数据不给结论；过度动画/花哨配色；超时；背稿照读；设备/格式翻车（提前检查 16:9 与投影）；数字前后矛盾。

- [ ] 能用“三个为什么”一句话讲清主线；开场先亮科学问题/贡献。
- [ ] 页数与时长匹配（约 1 分钟/页），含封面/目录/章节/致谢。
- [ ] 创新点凝练为 2–3 个，**无论文罗列页**。
- [ ] 每页主文字 ≤3 行；全篇无错别字，单位/姓名一致。
- [ ] 配色 ≤3 色、字体 ≤2 种、字号合规、元素对齐、留白充足。
- [ ] 版式匹配内容逻辑，符合 CRAP；过渡页/导航清晰。
- [ ] 关键数据有图且图上标注结论；复杂处有示意图/流程图/路线图；无模糊素材。
- [ ] 16:9、页脚单位/页号、动画稳重、文件大小合理。
- [ ] 页面是可讲的关键词提纲，无照读长句。
