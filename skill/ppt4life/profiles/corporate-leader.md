# 面向公司领导 / 高管 · 汇报 PPT 规范（Profile B）

> 适用：年终总结、工作汇报、项目汇报、方案提案、述职、争取资源/预算、复盘汇报。
> 核心认知：**领导没有时间，且要先知道答案，再看理由。** 一切围绕“让他 3 秒抓住结论、快速做决策”。

## 1. 内容逻辑：结论先行 + 金字塔原理

### 1.1 先搭骨架，别碰设计
动手前先写下汇报“三要素”：
1. **汇报目的**：申请资源 / 展示成果 / 复盘问题 / 提出方案（决定整份基调）。
2. **核心结论**：一句话说清想让领导记住什么。例：“Q3 销售额未达标，但已找到两个增长突破口。”
3. **领导关注点**：他最在意成本、进度、风险、团队还是客户？**把这些问题前置回答**。

### 1.2 经典结构：结论先行 + 分点论证 + 行动建议
- **封面页**：标题即结论（如“关于 XX 项目提前两周交付的汇报”，而非“XX 项目汇报”）。
- **摘要页（Executive Summary）**：3–5 点浓缩核心结论与关键数据；或用 2–3 句话横幅点明 So What。
- **正文页**：每页一个小结论，配支撑论据（数据、案例、对比）。
- **收尾页**：明确下一步计划与所需支持（要什么资源/谁配合/何时）。

### 1.3 金字塔原理与 SCQA
- **结论先行**，自上而下：先给结论，再逐级给论据；归类分组遵循 MECE（相互独立、完全穷尽）。
- **SCQA / SCR 框架**：Situation（共识背景）→ Complication（变化或风险）→ Question（由此产生的问题）→ **Answer（你的建议，直说）**。
- **行动标题（Action Title）**：标题写**结论句**而非主题标签。
  - 弱：“Q3 销售业绩” → 强：“Q3 收入增长 18%，全部来自企业客户续约”。
  - 检验法：把所有页标题按顺序抄下来读一遍，应像一段完整论证，而非目录。

### 1.4 一页一观点
每页只讲一个结论；标题里出现“和/；”说明该拆页。每页文字控制在 **≤6–7 行、每行 ≤15–20 字**；一屏文字总量建议 200 字以内，页面文字占比 30%–40%。

## 2. 版式：领导向“三板斧”模板（省 80% 设计时间）

| 版式 | 形态 | 适用 |
|---|---|---|
| **左文右图型** | 左侧 3–5 行要点文字，右侧放关键数据图/截图/流程图 | 问题分析、方案对比 |
| **全幅数据型** | 顶部结论（大号字）→ 中间一张清晰图表 → 底部一句简短解释 | 业绩回顾、趋势展示 |
| **流程步骤型** | 横向排 3–5 个步骤，每步配图标 + 一句说明 | 项目规划、实施路径 |

其他：可用 **卡片式**（成果/指标墙）、**时间轴**（年度节奏）、**2×2 矩阵/象限图**（策略框架）、**RAG 状态灯**（红/琥珀/绿灯标注风险与进度）。
通用版式法（拦腰/环绕/分割/全图）与 CRAP 四原则见 `references/layout-guide.md`。

## 3. 视觉规范

### 3.1 配色
- **只用“公司主色 + 黑/白/灰”**，全篇主色 ≤3 种；若公司有 VI，优先沿用品牌主色。
- 推荐组合（见 `assets/palettes/palettes.md`）：
  - **商务蓝**（万能百搭）：述职、工作总结、日常汇报，稳重专业。
  - **高级灰**（简约质感）：方案策划、项目汇报、提案答辩，低调有格调。
  - **暖棕系**（温柔大气）：年终总结、复盘汇报。
- **避雷**：不用高饱和大红大绿（刺眼廉价）；强调色只给关键数字与风险项。
- **RAG 状态色**：红#C9363C（风险/警告）、琥珀#D4920B（注意/中等）、绿#2A7D4F（安全/正面），用于进度灯与评级标签。

### 3.2 字体与排版
- 字体**全篇 ≤2 种**：标题微软雅黑/黑体加粗，正文微软雅黑常规（或标题无衬线、正文衬线）。
- 字号：**标题 24–36pt（投影场景标题建议 36pt+）、正文不小于 16–18pt**，行距 1.2–1.5 倍。
- 打开**网格线/参考线**对齐；留白均匀；开启**字体嵌入**防换电脑错乱。
- 层级靠字号/粗细/颜色区分：次要内容用浅灰弱化，重点用色块或加粗高亮。

### 3.3 数据与图表
- 把原始表格“翻译”成图表，并**在图上直接标注结论**（别让领导自己读表）。
- 选图：趋势→折线；占比→饼/环（分段 ≤5–6）；对比/排名→柱状/条形；关联→散点/气泡；策略→2×2 矩阵/瀑布图。
- 去冗余：删除多余网格线与图例，直接标注关键数；3–5 个核心指标足够（对比/占比最有说服力）。
- 禁用 3D 效果、截断坐标轴等误导性处理。

### 3.4 动画
只用于**引导节奏**：逐条出现要点、图表“擦除”式呈现；禁用旋转/弹跳等花哨效果。

### 3.5 配图（图文并茂，领导向）
- 领导场景默认走**“均衡”**配比；对外展示/年度亮点可选**“图多”**。
- 每页至少一张视觉元素：数据页配图表、路径页配流程/甘特、亮点页配实景图或产品图。
- 配图优先用**公司自有素材/实拍图**（更可信）；缺素材时用真实浏览器搜索下载（`references/browser-images.md`）或 AI 生图（`ImageGen`）。
- 图要**干净**：不放文字水印、不花哨堆叠；一张图讲一件事。图注/来源放小字。

## 4. 常见场景骨架

**年终/工作汇报**：封面(结论) → 摘要(核心成果数据) → 关键指标达成 → 重点项目/亮点 → 问题与风险(带 RAG) → 明年计划与所需支持 → 致谢。
**项目汇报/方案提案**：封面 → 摘要(SCQA,给建议) → 现状与问题 → 方案对比(矩阵) → 推荐方案与预期收益 → 实施路径(甘特/流程) → 风险与应对 → 需要的资源与决策 → 下一步。
**述职**：封面 → 摘要 → 职责与关键结果(量化) → 3 个核心亮点(数据) → 不足与复盘 → 下阶段目标 → 所需支持。

## 5. 表达话术

- 删掉“尊敬的领导、接下来我要介绍的是”等废话，留给口头讲。
- 每页标题用结论句；先结论后证据。
- 章节间用过渡句承上启下（“基于上述挑战，接下来提出三项优化方案”）。
- **结尾升华**：不只说“谢谢”，而用 1 页浓缩成果（图标化：“2 大项目落地、3 项指标超额”）+ 1 页下阶段具体目标，让领导看到规划与积极性。

## 6. 自检清单（交付前）

- [ ] 封面标题是**结论句**，不是主题标签。
- [ ] 有 Executive Summary 页（3–5 点或 2–3 句 So What）。
- [ ] 所有页标题为**行动标题**，连读成一段完整论证。
- [ ] 结论先行：建议/答案在前，证据在后（金字塔/SCQA）。
- [ ] 一页一观点；每页 ≤6–7 行、每行 ≤15–20 字。
- [ ] 关键数据已图表化，且图上标注了结论；核心指标 3–5 个。
- [ ] 配色 ≤3 色（公司主色 + 黑白灰），无高饱和刺眼色；RAG 用得克制。
- [ ] 字体 ≤2 种、字号合规（正文 ≥16pt）、已开启字体嵌入。
- [ ] 对齐/留白/重复统一（CRAP）；无花哨动画。
- [ ] 收尾有明确的**下一步计划与所需支持**。
