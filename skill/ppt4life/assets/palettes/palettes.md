# ppt4life 配色板（Palettes）

> 按汇报对象取用。通则：**全篇主色 ≤3 色**，强调色只给关键数字/结论/风险项。

## A. 科研 / 技术人群（Profile A）

### A1. 学术蓝（首选，最稳妥）
| 角色 | HEX | 用途 |
|---|---|---|
| 藏蓝 Primary | `#1F4E79` | 标题栏、强调块、图表主系列 |
| 学术蓝 | `#2E75B6` | 图表主系列/渐变 |
| 浅灰底 | `#F2F2F2` | 卡片/分区底色 |
| 纯白 | `#FFFFFF` | 页面底色 |
| 深灰文字 | `#262626` | 正文主文字 |
| 学术橙（强调） | `#ED7D31` | 关键数字、创新点、结论（慎用但醒目） |

### A2. 深海军蓝（封面/章节主视觉）
| 角色 | HEX |
|---|---|
| 主底 | `#0F2C4C` |
| 高亮 | `#2E75B6` |
| 点缀 | `#ED7D31` |

### A3. 灰度专业风
`#333333`（主墨）/ `#666666`、`#999999`（辅助）/ `#F5F5F5`（浅底）/ 强调 `#1F4E79` 或 `#ED7D31`。

## B. 公司领导 / 高管（Profile B）

> 通则：**公司主色 + 黑/白/灰**；若公司有 VI，优先沿用品牌主色。

### B1. 商务蓝（万能百搭：述职、工作总结、日常汇报）
| 角色 | HEX | 用途 |
|---|---|---|
| 深皇家蓝 | `#1A3A6B` | 标题、表头、主要图表填充 |
| 辅助蓝 | `#2E5C9A` | 次级图表系列 |
| 锐利黑（文字） | `#1A1A1A` | 正文 |
| 多阶灰 | `#444444` / `#777777` / `#BBBBBB` / `#EEEEEE` | 信息层级区分 |
| 背景 | `#FFFFFF` | 页面底 |

### B2. 高级灰（简约质感：方案策划、项目汇报、提案答辩）
`#2F3437`（主墨）/ `#5C666A`、`#98A0A4`（辅灰）/ `#E8EAEB`（浅底）/ 强调 `#1A3A6B`。

### B3. 暖棕系（温柔大气：年终总结、复盘汇报）
`#5A4632`（主棕）/ `#8C7355`（辅）/ `#F5F1EA`（浅底）/ 文字 `#2B2B2B` / 强调 `#B8860B`。

### B4. RAG 状态色（领导向专用：进度/风险/评级）
| 状态 | HEX | 含义 |
|---|---|---|
| 红 Red | `#C9363C` | 风险 / 警告 / 未达标 |
| 琥珀 Amber | `#D4920B` | 注意 / 中等 / 有风险 |
| 绿 Green | `#2A7D4F` | 安全 / 正面 / 已达成 |

用法：做成小型 pill/badge（圆角矩形）状态灯或进度条；**同一页不超过 2 处彩色强调**。

## 避雷
- 不用高饱和大红大绿（刺眼廉价）；不用彩虹色图表。
- 图表系列色最多 3–4 个，从主色渐变与中性灰中取。
- 含涨跌/业绩语义时遵循本地惯例：**涨红跌绿**。
