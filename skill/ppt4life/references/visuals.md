# 配图与视觉素材策略（Visuals）

> **铁律：图文并茂。** 任何一页都不应该只有纯文字段落——至少配 图 / 表 / 逻辑图示 / 图标 之一。纯文字页面干瘪、说服力弱、领导不看。

## 1. 第二步选择：图文配比（图多 / 均衡 / 字多）

在选定汇报对象后，**再让使用者选一次“图文配比”**（默认推荐“均衡”）：

| 选项 | 含义 | 适用场景 | 页面特征 |
|---|---|---|---|
| **图多** | 视觉主导，文字只做关键词标注 | 品牌/方案展示、产品发布、年度亮点、对外招商、大场面宣讲 | 大图/全图/多图拼版；每页 1 句话 + 图 |
| **均衡（推荐）** | 图文并茂，图与文各司其职 | 绝大多数汇报/答辩 | 左文右图、上结论下图表、卡片配图标 |
| **字多** | 信息密集，但**仍禁止纯文字墙** | 数据分析、技术方案细节、制度/流程说明、评审细则 | 表格 + 逻辑图 + 关键句加粗；用图示化解文字 |

> 无论选哪种，**“字多”也不等于堆文字**：把段落拆成“结构化图示 + 关键词”，用表格/流程图/矩阵替代大段描述。

## 2. 每页都问一句：这页的图在哪？

- 有数据的页 → 必须有**数据图**（柱/折线/饼/瀑布/热图），并在图上标注结论。
- 有流程的页 → 必须有**流程图/路线图**。
- 有对比的页 → 必须有**对比表或对比图/矩阵**。
- 讲概念的页 → 配**示意图/图标/高质量实景图**。
- 只有文字没有图的页 → 视为未完成，回去补图。

## 3. 配图来源与选择优先级

按“真实、合规、清晰”优先：

1. **用户提供的素材**（公司实拍、产品图、单位 LOGO、已发布图表）——最优先，直接用。
2. **浏览器搜索下载真实素材** → 需要真实照片/实景/新闻配图时，用 `bsk` 控制真实浏览器搜索并下载。**操作手册见 `references/browser-images.md`**。
3. **AI 生图** → 缺真实素材、需要概念图/背景/插画/示意图时，用 `ImageGen` 工具生成（见第 4 节）。
4. **矢量自绘** → 数据图、流程图、逻辑图、矩阵图，**优先自绘**（最严谨、可编辑、风格统一），尤其科研/数据场景。

> 选择逻辑：**数据/逻辑 → 自绘图表；要真实感 → 浏览器找实景图；要概念/氛围/没有现成素材 → AI 生图。**

## 4. AI 生图（ImageGen 工具）

需要 AI 生成配图（背景图、概念插画、示意图、风格化视觉）时：

1. 通过 **ToolSearch** 发现 `ImageGen`，再用 **DeferExecuteTool** 调用（文生图 / 图生图）。
2. Prompt 要点：说明**用途与版式**（如“16:9 横向 PPT 背景图，深蓝商务风，右侧留白放文字”）、**风格**（商务/学术/科技/扁平）、**配色**（贴合该场景色板）、**留白位置**（便于压文字）。
3. 生成后**下载到工作区**（如 `assets/img/`），再嵌入 PPT。
4. 用图原则：AI 图适合做**氛围/背景/概念示意**，**不要**用它伪造数据、图表或真实人物场景。

## 5. 图片落地规范

- **分辨率**：宽度 ≥1920px（16:9 铺满页需更大，≥2560px 更稳）；模糊图宁可用矢量自绘。
- **比例**：与版式匹配（全屏 16:9、卡片图 4:3/1:1、人物竖图 3:4）；**不拉伸变形**，必要时裁剪。
- **批量预处理**：用 `scripts/fetch-images.py --fit 16:9 --max-width 1920` 可把下载的大图**居中裁剪 + 等比限宽**，直接得到版式可用的尺寸（需 Pillow）。
- **风格统一**：全篇图片调性/色温一致；同类图加统一描边或圆角，弱化杂色。
- **统一观感（批量）**：`scripts/fetch-images.py --style card` 会给每张图套**白底圆角+细描边**，让不同来源的素材拼在一页也不违和（需 Pillow）。
- **存放**：下载/生成后统一存到工作区 `assets/img/`，按语义命名（如 `hero-bg.jpg`、`q3-revenue-chart.png`）。
- **版权合规**：优先用免版权图库（Unsplash / Pexels / Pixabay）或公司自有素材；标注来源；不用来源不明或有争议的图片。
- **标注出处**：用 `scripts/fetch-images.py --cite` 会自动生成一页 **`图片来源.pptx`**（16:9，文件 ↔ 来源 URL + 版权提示）与 `_sources.md`，可直接附在 PPT 末尾或备注里。
- **压字处理**：全图铺底压文字时加 **30%–50% 半透明蒙版**（见 `layout-guide.md`）。

- [ ] 图片清晰（宽 ≥1920px）、不变形、风格统一。
- [ ] 图片已下载到本地 `assets/img/`，PPT 嵌入的是本地文件。
- [ ] 图片来源合规，已标注出处（必要时）。
