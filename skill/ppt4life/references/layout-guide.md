# 通用排版布局指南（Layout Guide）

> 适用于所有汇报对象。**先定版式骨架，再上色上字**——版式选对，内容就成功了七八成。

## 1. 五大万能版式（按内容逻辑选，覆盖 90% 场景）

| 版式 | 页面形态 | 适配逻辑 | 典型用途 |
|---|---|---|---|
| **拦腰版式** | 色块把页面横切成上/下两块，上总述下分点 | 总分 / 并列 | 章节引言、观点总结、板块概述 |
| **环绕版式** | 中心放核心主题，次要文案/图形环绕四周 | 总分 / 循环 / 并列 | 闭环、流程循环、多维分析（圆形可改燕尾箭头表循环） |
| **分割版式** | 线条/色块均分多区，每区一板块，细箭头串联 | 递进 / 并列 | 步骤拆解、阶段汇报、要点对比 |
| **卡片版式** | 多个等宽矩形卡片排成矩阵，模块化分区 | 总分 / 递进 / 并列 | 工作总结、成果矩阵、数据指标墙 |
| **全图版式** | 高清图铺满做底，文字压中央（可加蒙版） | 氛围 / 强调 | 封面、结尾页、单点打动 |

补充常见组合：**满屏**（封面冲击）、**上下**（上标题下内容，字多时）、**左右**（左文右图/左图右文，符合从左到右阅读习惯，右端补元素防失衡）、**三分式**（上标题、下主体、中部铺满）。

> 新手优化：长文拆短句 → 短句提炼关键词 → 按版式分放；卡片/拦腰去除多余渐变与杂色，极简更高级。

## 2. CRAP 排版四原则（逐页核对）

1. **对齐 Alignment**：任何元素都不要随手放，都对齐到某一隐形参考线（左对齐/居中/网格）。
2. **对比 Contrast**：用字号、粗细、颜色区分重要性，把重点“逼”出来。
3. **亲密 Proximity**：相关信息物理靠近、无关分开，形成清晰信息组。
4. **重复 Repetition**：颜色、字体、图标、版式风格全篇重复，形成整体一致感。

## 3. 三三原则（上版式前的瘦身）

- **一页一核心观点**；
- **要点 ≤3 个**（最多 5 条）；
- **每条 ≤3 行**，超了拆页或图表化。
> 某页文字过多时先做减法，再谈版式；拥挤页面永远是观感杀手。

## 4. 栅格分区与多页型

- 用**栅格**保证模块对齐、留足页边距；页面按功能分为 **标题区 / 核心图文区 / 结论区**，以留白区分。
- 标题置顶统一，正文区按网格划分（两栏图+文、等宽卡片列等）；数据图预留占位、图注清晰。
- **多页型套用**：封面 → 目录 → 章节页 → 正文 → 过渡页 → 总结。过渡页用整行大标题 + 低干扰图形，提示“进入新章节”，帮听众复位注意力。

## 5. 蒙版与背景

- 图片铺底压字时，用纯色/渐变**半透明蒙版**降干扰，蒙版色取画面主色调。
- 透明度建议 **30%–50%**，可全屏或半屏蒙版。
- 画面**不能太满，需要留白**；主体放一侧时另一侧补设计元素防失衡。

## 6. 配色在版式中的落地

- **颜色不过三**，可按 **6:3:1** 分配主色:辅助色:点缀色。
- 需多级同色系时切成 **HSL**，**色相跨度控制在 60 之内**得到同一色系深浅。
- 图表/卡片填充统一从主色渐变与中性灰取色，避免彩虹色；强调色只给关键数字/结论。
- 各人群具体色板见 `assets/palettes/palettes.md`。

## 7. 字号与字重层级

- 标题加粗（确立页面主题），正文常规字重（保证舒适）；关键数据/结论可用中等加粗、变色突出。
- 以“标题粗重醒目 → 正文纤细清晰”制造张弛节奏，让观众一眼抓住重点。
- 字体全篇 ≤2 种、字号规范统一，建议用**幻灯片母版**固化格式。

## 8. 排版自查

- [ ] 每页选定了明确版式，且与内容逻辑匹配。
- [ ] 对齐：元素对齐到参考线，无随手摆放。
- [ ] 对比：每页有一眼可见的重点（字号/颜色/加粗）。
- [ ] 亲密：信息已分组成清晰单元。
- [ ] 重复：全篇颜色、字体、图标、版式统一。
- [ ] 文字按三三原则瘦身；画面有留白、不拥挤。
- [ ] 页边距合适（内容区四周留空，左右约 2cm 观感舒适）。
- [ ] 复杂逻辑（流程/闭环/层级/对比）已用结构化图示表达，非纯文字。
- [ ] 封面/目录/章节过渡页齐备，导航清晰。
