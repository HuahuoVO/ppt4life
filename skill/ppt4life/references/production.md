# 生产规范（Production）

> 任何场景通用的产出标准：把方法论落成一份真正能打开、能改、能讲的文件。

## 1. 产出格式优先级

1. **PPTX（首选）**：每页一个版式、文字是**真文字可编辑**（不是图片），便于用户二次修改。
   - 用**幻灯片母版**固化：字体、字号层级、配色、页眉 LOGO、页脚页号，保证全篇一致且可批量改。
   - 开启**字体嵌入**，杜绝换电脑排版错乱。
2. **16:9 高保真 HTML（次选）**：当环境无法生成 PPTX 时，产出每屏一页的 HTML，并明确告知用户可再转 PPTX。
3. 图表尽量用**原生可编辑图表**或矢量图形，而非截图。

## 2. 页面与工程规范

- **比例：16:9**（现代投影与线上会议默认）。
- **文件大小**：科研/答辩系统常见上限 ≤200M；成果交付尽量精简。
- **嵌入媒体**：用通用格式（MP4/H.264、GIF 等），避免特殊编码导致无法导出或播放。
- **图片**：用高清原图；无高清素材时用**可编辑矢量图形/示意框图**代替，**不用模糊截图占位**。
- **页眉/页脚**：统一放单位或公司 LOGO 与页码，增强归属感与检索性。
- **版权**：素材来源合规，避免有版权争议的图片。

## 3. 通用文字与图表底线

- 文字**关键词化、短句化**，不做大段；页面是可讲的提纲，不是演讲稿。
- 每页能回答“这页我到底想表达哪一句结论”。
- 图表：趋势→折线；占比→饼/环（分段 ≤5–6）；对比/排名→柱状/条形；关联→散点/气泡；流程→流程图；策略→2×2 矩阵/象限。
- 图表去冗余（多余网格线、图例），**关键数字直接标注**；禁用 3D 与截断轴等误导处理。

## 4. 中国地域惯例

- 涉及市场/业绩、涨跌、金融数据时遵循本地语义：**涨红跌绿**（与欧美相反）；币种默认 **¥**。
- 图表用色以清晰、克制为准，不因强调而牺牲可读性。

## 5. 交付

- 文件保存到当前工作区，命名清晰（如 `XX项目汇报_16x9.pptx`），并提示用户可下载编辑。
- 如需可同步给出**演讲者备注**（每页 30 秒内可讲完的结论要点）。

## 6. 通用自检清单（交付前必过）

- [ ] 已确认汇报对象并加载对应 profile（科研/领导）。
- [ ] 页数与汇报时长匹配（未给时长按约 1 分钟/页倒推并标注假设）。
- [ ] 16:9；母版统一；字体已嵌入；文件体积合理。
- [ ] 每页一核心；文字已瘦身；全篇无错别字、名称/数字前后一致。
- [ ] 版式匹配内容逻辑，符合 CRAP；留白充足、元素对齐。
- [ ] 配色 ≤3 色（或公司主色 + 黑白灰）、字体 ≤2 种、字号达标。
- [ ] 关键数据已图表化并标注结论；无模糊素材。
- [ ] **图文并茂**：没有任何一页是纯文字段落墙；配图已按所选图文配比落地到 `assets/img/` 并嵌入。
- [ ] 动画克制；无花哨切换与音效。
- [ ] 封面/目录/章节过渡/收尾齐备；收尾有明确的下一步或所需支持。
- [ ] 已过所选 profile 的专属自检清单。
