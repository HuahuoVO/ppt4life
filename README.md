# ppt4life · 多场景 · 图文并茂 PPT 制作技能

> **PPT for life** —— 献给每一位要靠汇报讨生活的人。
> 科研要答辩、打工人要汇报，对象不同，PPT 就该是两套逻辑。

## 这是什么

一个**多场景、图文并茂**的 PPT 制作 Agent Skill：启动后先让你选两件事——① 汇报对象 ② 图文配比，再按该人群专属的「内容逻辑 + 版式布局 + 配色 + 配图策略 + 话术」产出演示文稿。

**两条硬规则**：
1. **先选场景**，不擅自假设。
2. **图文并茂**——任何一页都不允许是纯文字段落墙，每页至少配 图 / 表 / 逻辑图示 / 图标 之一。

## 启动时的两个选择

### ① 汇报对象

| 选项 | 面向谁 | 典型场景 | 内容逻辑 |
|---|---|---|---|
| **A. 科研 / 技术人群** | 评审专家、基金委、答辩评委 | 杰青·优青·青年基金 A/B 类、国自然、科技奖报奖、论文/学位答辩、教学比赛课件 | **三个为什么** |
| **B. 公司领导 / 高管** | 老板、管理层、决策层 | 年终总结、工作汇报、项目汇报、方案提案、述职、争取资源 | **结论先行 + 金字塔原理** |

### ② 图文配比

| 选项 | 含义 | 适用 |
|---|---|---|
| **图多** | 视觉主导，文字只做关键词 | 品牌/方案展示、产品发布、年度亮点、对外宣讲 |
| **均衡（推荐）** | 图文并茂，图与文各司其职 | 绝大多数汇报/答辩 |
| **字多** | 信息密集，但**仍禁止纯文字墙**，用表格/逻辑图化解 | 数据分析、技术方案细节、制度流程 |

## 配图来源（三选一，按“真实、合规、清晰”优先）

1. **用户自有素材**（实拍/产品图/LOGO）——最优先。
2. **浏览器搜索下载真实素材**——融合 [Tencent/BrowserSkill](https://github.com/Tencent/BrowserSkill)（`bsk` CLI），用**你已登录的真实浏览器**搜索并下载图片（免版权图库优先）。手册见 `references/browser-images.md`，一键脚本 `skill/ppt4life/scripts/fetch-images.py`。
3. **AI 生图**——缺现成素材的概念/背景/插画，用 `ImageGen` 工具生成。
4. **矢量自绘**——数据图/流程图/逻辑图/矩阵，**优先自绘**（最严谨、可编辑）。

> 选择逻辑：**数据/逻辑 → 自绘；要真实感 → 浏览器找图；要概念/氛围 → AI 生图。**
> `bsk` 或 `ImageGen` 不可用时**不卡住**，回退矢量自绘。

## 示例（Showcase）

仓库内含两份示例成品，分别对应两个汇报对象 profile（均为 16:9，图文并茂，pptx + html 双份）。

### 示例一：面向公司领导 · *2026 年 Q3 经营分析汇报*（10 页，Profile B）

- `examples/ppt4life_领导工作汇报_示例.pptx` / `.html`

| 页面 | 体现的要点 |
|---|---|
| 封面 | **标题即结论**（“Q3 收入达标 118%…建议 Q4 加倍投入”） |
| 框架页 | 导航式汇报框架（结论→证据→行动） |
| Executive Summary | 一句话结论 + 4 个结论卡 |
| 关键指标 | KPI 卡片 + **RAG 状态灯** + “So What” 解读 |
| 业绩回顾 | **原生柱状图** + 结论标注（图文并茂） |
| 增长引擎 | 左文右图 + 大数字块 |
| 风险与应对 | **RAG 状态表**（红/琥珀/绿） |
| 方案对比 | 三方案对比，推荐项高亮 |
| 下一步 | 时间轴 + “需要的决策/资源” |
| 结尾 | 成果图标化 + 下阶段目标（结尾升华） |

### 示例二：面向科研技术人群 · *青年科学基金（B 类）答辩*（12 页，Profile A）

- `examples/ppt4life_科研答辩_示例.pptx` / `.html`

| 页面 | 体现的要点 |
|---|---|
| 封面 | 项目名 + 申请人/单位/日期，学术蓝主视觉 |
| 框架页 | 按“**三个为什么**”组织（为什么选我 / 为什么做这方向 / 为什么能做成） |
| 个人简介 | **一句话学术定位** + 经历**时间轴** |
| 代表成果 | 量化指标卡（质量 > 数量，**不罗列论文清单**） |
| 研究背景 | **痛点→局限→科学问题** 箭头递进图 + 问题凝练 |
| 创新点 | 3 张创新卡（背景意义→成果特色→价值） |
| 技术路线 | **三模块流程图** + 闭环反馈 |
| 研究基础 | **原生柱状图**（预实验数据）+ 可行性支撑 |
| 研究计划 | **甘特图**（分年度 + 里程碑） |
| 团队平台 | 梯队数字 + 平台条件 |
| 预期成果 | 成果指标 + 科学/应用价值 |
| 致谢 | 简洁致谢页 |

## 工作流

```
0 选择：① 汇报对象  ② 图文配比
   ↓
1 需求澄清（场景 / 时长页数 / 素材 / LOGO-VI）
   ↓
2 定核心主张（三个为什么 或 结论先行）
   ↓
3 分场景结构（页面骨架 → 逐页脚本，标注每页配什么图）
   ↓
4 配图与素材（自绘 / 浏览器搜索下载 / AI 生图 → assets/img）
   ↓
5 版式与视觉（通用版式法 + 人群配色）
   ↓
6 生成演示文稿（优先 PPTX，其次 16:9 HTML）
   ↓
7 自检（通用 + 配图 + 人群专属）
```

## 使用方法

1. 将 `skill/ppt4life/`（或直接导入 `dist/ppt4life.zip`）安装为本地 Skill。
2. 对 AI 说：“帮我做一份 PPT”。
3. 它会先问你**汇报对象**与**图文配比**，你选完再给材料即可。
   也可直接说：“给领导做一份图文并茂的年终汇报 PPT，材料如下……”
4. 需要真实配图时，若已装好 BrowserSkill（`bsk` + 浏览器扩展），技能会驱动你的真实浏览器搜索并下载图片。

## 依赖（可选，按需）

- **BrowserSkill**（真实图片素材）：`bsk` CLI + 浏览器扩展。安装与用法见 `skill/ppt4life/references/browser-images.md`。
- **ImageGen**（AI 生图）：由运行环境提供的内置工具，无需额外安装。

### 一键搜图（配好 BrowserSkill 后）

```bash
python skill/ppt4life/scripts/fetch-images.py --query "business meeting" --count 6 --out ./assets/img
```

自动完成：起会话 → 打开图库 → 抽图片直链 → 下载到 `assets/img/` → 停会话，并写 `_sources.json` / `_sources.md` 记录出处。
支持 `--source unsplash|pexels|pixabay|bing|baidu`，`--dry-run` 可先看计划；
加 **`--fit 16:9 --max-width 1920`** 会把大图居中裁剪+等比限宽成版式可用尺寸（需 Pillow）；
加 **`--cite`** 会额外生成一页 16:9 的 **`图片来源.pptx`**（文件 ↔ 来源 URL + 版权提示），便于在答辩/汇报里标注出处。

## 设计原则

- **先选对象，再谈设计**：给评审的和给老板的完全是两套逻辑，不混用。
- **图文并茂**：每页都要有图/表/图示，拒绝纯文字墙。
- **结论驱动**：科研讲“贡献与创新”，领导汇报讲“答案与决策”。
- **版式先行**：先定版式骨架，再上色。
- **CRAP 四原则**：对齐、对比、亲密、重复。
- **克制**：配色 ≤3 色、字体 ≤2 种、动画只用于引导。
