# ppt4life · 多场景 PPT 制作技能

> **PPT for life** —— 献给每一位要靠汇报讨生活的人。
> 科研要答辩、打工人要汇报，对象不同，PPT 就该是两套逻辑。

## 这是什么

一个**多场景**的 PPT 制作 Agent Skill：启动后先让你选**汇报对象**，再按该人群专属的「内容逻辑 + 版式布局 + 配色 + 话术」产出演示文稿。

## 支持的汇报对象

| 选项 | 面向谁 | 典型场景 | 内容逻辑 |
|---|---|---|---|
| **A. 科研 / 技术人群** | 评审专家、基金委、答辩评委 | 杰青·优青·青年基金 A/B 类、国自然、科技奖报奖、论文/学位答辩、教学比赛课件 | **三个为什么**（为什么选你 / 为什么做这方向 / 为什么能做成） |
| **B. 公司领导 / 高管** | 老板、管理层、决策层 | 年终总结、工作汇报、项目汇报、方案提案、述职、争取资源 | **结论先行 + 金字塔原理**（SCQA、行动标题、So What） |

> 后续可继续扩展人群（如面向学生授课、面向客户销售），只需在 `profiles/` 增加对应 profile。

## 工作流

```
0 选择汇报对象（科研技术 / 公司领导）
   ↓
1 需求澄清（场景 / 时长页数 / 素材 / LOGO-VI）
   ↓
2 定核心主张（三个为什么 或 结论先行）
   ↓
3 分场景结构（套该人群页面骨架 → 逐页脚本）
   ↓
4 版式与视觉（通用版式法 + 该人群配色）
   ↓
5 生成演示文稿（优先 PPTX，其次 16:9 HTML）
   ↓
6 自检（通用清单 + 人群专属清单）
```

## 使用方法

1. 将 `skill/ppt4life/`（或直接导入 `dist/ppt4life.zip`）安装为本地 Skill。
2. 对 AI 说：“帮我做一份 PPT”。
3. 它会先问你**汇报对象**（科研技术 / 公司领导），你选完再给材料即可。
   也可直接说：“给领导做一份年终汇报 PPT，材料如下……”

## 设计原则

- **先选对象，再谈设计**：给评审的和给老板的完全是两套逻辑，不混用。
- **结论驱动**：科研讲“贡献与创新”，领导汇报讲“答案与决策”。
- **版式先行**：先定版式骨架（拦腰/环绕/分割/卡片/全图），再上色。
- **CRAP 四原则**：对齐、对比、亲密、重复。
- **克制**：配色 ≤3 色、字体 ≤2 种、动画只用于引导。

## 说明

- 方法论为对汇报场景通用评审/决策要求与视觉规范的系统总结。
- 科研评审规则随政策变化（如 2025 年起杰青/优青更名青年科学基金 A/B 类），使用前请结合当年官方要求核对。
- 涉及涨跌/业绩数据时遵循本地惯例：**涨红跌绿**。
